In the following code, what is going to be printed after 'y='? (note: the answer is not a specific value.) Why does this happen?

	printf("x=%d y=%d", 3);
    
Because printf uses the format string to decide how many arguments to read. The format string has two %d conversions, but only one argument was passed, so the second va_arg reads an unspecified value from where the next argument would have been.
